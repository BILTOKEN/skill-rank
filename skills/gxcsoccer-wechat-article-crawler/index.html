抓取微信公众号文章，导出结构化数据和 Markdown，自动下载图片绕过防盗链 | 用于爬取微信文章的 Claude Code skill

⚡ 一键复制提示词 ?

请使用 wechat-article-crawler 技能抓取指定微信公众号文章。

操作步骤：
1. 提供目标文章的链接或公众号名称
2. 自动提取文章内容、标题、作者、发布时间等结构化数据
3. 导出为 Markdown 格式，并自动下载文章中的图片（绕过防盗链）
4. 将结果保存到本地文件

示例用法：
- 抓取单篇文章：提供文章 URL
- 批量抓取：提供公众号名称和文章数量

注意：请确保遵守相关法律法规和微信平台的使用条款。
