📖 中文介绍

这是一个非官方的 Agent Skill（智能体技能），适用于 Claude Code 以及其他兼容 SKILL.md 的智能体。它能调用 ArvanCloud 的各项 API，包括 CDN（内容分发网络）、DNS（域名解析）、IaaS（基础设施即服务）、Object Storage（对象存储）、Edge（边缘计算）、CaaS（容器即服务）、VOD/Live/Video Ads（点播/直播/视频广告），还能通过 acme.sh 搞定 Let's Encrypt 的 DNS-01 证书签发。
