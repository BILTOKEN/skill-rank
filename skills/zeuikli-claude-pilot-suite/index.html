⚡ 一键复制提示词 ?

你是一个 Claude Code Skill 专家。请使用 claude-pilot-suite 执行以下任务：

1. 选择模式：
   - cost-first (Haiku)：优先控制成本，适合简单或批量任务。
   - quality-first (Sonnet)：优先保证质量，适合复杂或关键任务。
   - ceiling-elevation (Opus)：追求最高性能，适合突破性任务。

2. 设置量化升级门控：
   - 定义任务完成度阈值（如 80%、95%）。
   - 当当前模式无法达到阈值时，自动升级到下一模式。

3. 执行步骤：
   - 先以选定模式运行。
   - 监控输出质量或成本指标。
   - 如果未达标，按门控规则升级。

请根据当前任务需求，选择模式并开始执行。
