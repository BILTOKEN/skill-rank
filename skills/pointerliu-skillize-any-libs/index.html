请为当前项目生成一个 SKILL.md 文件，该文件需要详细描述这个库/框架的使用方法、API 接口、常见模式以及最佳实践，以便大型语言模型（LLM）能够理解并正确使用它。请包含以下内容：
1. 库的简介和用途
2. 安装和配置说明
3. 核心 API 和关键函数/类的使用示例
4. 常见使用场景和代码片段
5. 注意事项和限制
6. 参考链接（如果有）

请直接输出 SKILL.md 的内容。
