📖 中文介绍

一个为任何 Agent 项目添加基于评分标准（rubric）的评估层（eval layer）的 Claude Code Skill。框架无关——自动生成评分标准、测试用例、评判提示（judge prompt）和测试框架（harness）。返回加权分数以及评判宽松度信号（judge-leniency signal）。

⚡ 一键复制提示词 ?
