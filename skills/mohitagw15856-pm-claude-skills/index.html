这个仓库提供 1,310 个专业 Agent Skills（智能体技能），适用于 Claude、Claude Duet、ChatGPT、Gemini、Cursor 和 Codex。技能覆盖 PRD（产品需求文档）、事故复盘（postmortem）、租约、医疗账单、工资单、晨间简报等场景。其中 21 个技能专为 Claude Duet 这类常驻型 Agent 打造。全部是纯 Markdown 文件，采用 MIT 协议，已收录进 Anthropic 的插件目录。可以在浏览器里免费用，也可以运行 npx pm-claude-skills add 安装。
